# Barber Giyos — Booking

Sartaroshxona uchun onlayn navbat olish (booking) tizimi.

## Papka strukturasi

```
backend/     — server (API, ma'lumotlar bazasi)
  src/
frontend/    — mijoz uchun interfeys (web sayt)
  src/
docs/        — hujjatlar, rejalar, diagrammalar
```

## Boshlash

Loyiha hozircha boshlang'ich holatda. Texnologiya tanlangach, bu bo'lim to'ldiriladi.

## Rejalashtirilgan imkoniyatlar

- [ ] Xizmatlar ro'yxati (soch olish, soqol, va h.k.) va narxlar
- [ ] Sartaroshlar va ularning ish jadvali
- [ ] Bo'sh vaqtlarni ko'rsatish va navbat band qilish
- [ ] Mijozga tasdiq / eslatma yuborish
- [ ] Admin panel — navbatlarni boshqarish
